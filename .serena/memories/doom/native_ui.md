# Doom native UI invariants

- Engine adapter `doom/rp2040-doom/src/fcpico/ui_capture.c` snapshots semantic status and menu selection; `doom/port/video/fcui.c` packs v4 UI state. `doom/tools/build_native_status_probe.py` owns resident CHR/OAM rendering in the erasable ROM; `doom/sim/mesen2/run_native_status_probe.py` exercises that ROM with a synthetic v4 stream. Mesen does not execute the RP2350 Doom engine or prove physical PIO/DMA timing.
- V4 mailbox is 144 bytes; calibrated NES-001 read count is 15122 because 28 native background text tiles are omitted from the picture stream. Preserve the fixed read schedule and permanent fix bank. Protocol fields come from `fcbus_protocol.h`; regenerate derived constants with `gen_protocol.py`.
- NES sprites permit eight entries per scanline and 64 total. Current resident `$1800` atlas uses 24 tall-glyph tiles and eleven 3x3 face variants (123 of 128 tiles). The title logo uses 24 tiles at sprite `$1600` (`$60..$77`); episode paired glyphs use 19 tiles at sprite `$1000` (`$00..$12`). The title logo displays only when status is absent: 35 status OAM + 26 menu glyph slots + cursor leave two slots during gameplay. Lower-half CHR art passes Mesen but needs physical validation; do not infer device capacity from emulator RAM.
- Native status occupies y=192..239, reserves BG palette 3 for dark/gray/light/red backing and native background ammo row 28. During status display, world attribute selection uses palettes 0..2. Sprite text uses red with a dark in-tile shadow; avoid extra shadow sprites because of OAM limits. Native menu sprites draw over the world without a black mask; `M_Drawer` suppresses original item labels and skull only for native menu IDs 1..5. Dynamic load/save text and other titles still use converted game graphics.
- Physical HR-12 confirms red native text, gray backing, idle/ouch/pickup face behavior on NES-001; see `doom/HARDWARE-LOG.md` for dated evidence. Plan 12 and HR-13 cover the newer styled backing, title sprite logo, and actual shareware episode names. Do not store transient artifact hashes or candidate status here.
