# Doom native UI invariants

- Engine adapter `doom/rp2040-doom/src/fcpico/ui_capture.c` snapshots semantic status and menu selection; `doom/port/video/fcui.c` packs v4 UI state. `doom/tools/build_native_status_probe.py` owns resident CHR/OAM rendering in the erasable ROM; `doom/sim/mesen2/run_native_status_probe.py` exercises that ROM with a synthetic v4 stream. Mesen does not execute the RP2350 Doom engine or prove physical PIO/DMA timing.
- V4 mailbox is 144 bytes; calibrated NES-001 read count is 15122 because 28 native background text tiles are omitted from the picture stream. Preserve the fixed read schedule and permanent fix bank. Protocol fields come from `fcbus_protocol.h`; regenerate derived constants with `gen_protocol.py`.
- NES sprites permit eight entries per scanline and 64 total. Resident `$1800` atlas uses 24 tall-glyph tiles and eleven 3x3 face variants (123 of 128 tiles). The title logo uses 32 tiles at sprite `$1600` (`$60..$7F`). Paused main menu uses an 18-tile, 48x24 logo at `$11F0` (`$1F..$30`), 14 paired-label sprites, 31 status sprites and one cursor: all 64 OAM entries. Static H/R status labels render in the native background stream, freeing four OAM entries. Episode and main paired glyphs occupy 31 tiles at `$1000` (`$00..$1E`); episode labels use 21 OAM entries. Both logos derive from `M_DOOM`; a block-letter substitute was rejected visually. Lower-half CHR art passes Mesen but needs physical validation; do not infer device capacity from emulator RAM.
- Native status occupies y=192..239, reserves BG palette 3 for dark/gray/light/red backing and native background ammo row 28. During status display, world attribute selection uses palettes 0..2. Number sprites begin at visible y=198 and 206; the 3x3 face begins at y=198 and ends at 221, inside the panel divider. Sprite text uses red with a dark in-tile shadow; avoid extra shadow sprites because of OAM limits. Native menu sprites draw over the world without a black mask; `M_Drawer` suppresses original item labels and skull only for native menu IDs 1..5. Dynamic load/save text and other titles still use converted game graphics.
- Physical HR-12 confirms red native text, gray backing, idle/ouch/pickup face behavior on NES-001. Physical HR-13 photo shows 9010's number/face misalignment and missing paused-menu logo; it does not establish title-logo behavior. Plan 12 and HR-14 cover the corrected layout and source-derived paused logo. See `doom/HARDWARE-LOG.md` for dated evidence. Do not store transient artifact hashes or candidate status here.
