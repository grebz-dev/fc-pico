# Doom audio integration

- `doom/tools/audio/build_bank.py` converts a caller-supplied shareware WAD into local `audio.bin`, matching C tables and `audio.json`. Do not commit WAD or generated bank bytes. `FCPICO_AUDIO_WAD` enables optional engine integration; converter Python needs numpy.
- The archive uses the reserved `FLASH_ASSETS_ADDR` region, not the firmware region before WHX. Device tables hold XIP pointers; host tables embed the same bytes. Generated getter checks the archive identity prefix against compiled tables before installing the default bank. This pairs files; it is not a runtime full-payload checksum. Explicit caller banks take precedence.
- An audio-enabled firmware-only UF2 does not install its archive. Use the complete firmware + WHX + audio image. `whx2uf2.py --audio` validates archive bounds/WHX overlap; `build_shadow_detail.sh` merges assets when `FCPICO_AUDIO_WAD` is set and explicitly clears that cache option when omitted. `build_bg_text_probe_device.sh --native-status` inherits this option and preserves native HUD ROM generation.
- Device sequencer advancement belongs to core 0's accepted bus-heartbeat IRQ, after DMA re-arm, preparing the next mailbox. Engine sequencer mutations/queries, initialization and pumps exclude local interrupts. Core 1 polls do nothing; additional core 0 polls at the same heartbeat do not advance twice. Avoid moving advancement back to engine/render polls: rendering stalls can stretch tempo.
- Host `--dump-apu` uses synthetic rendered-frame heartbeats; it captures register writes and does not synthesize sound or execute ARM IRQ timing. Serial `[audio]` counters expose bank presence, music state, frames, maximum pairs, deferred/dropped writes and max IRQ duration. Native NMI tests and Mesen UI probes have narrower evidence than physical audio/IRQ measurements.
- Hardware outcome, exact candidate hashes, measurements and current acceptance status belong in `doom/HARDWARE-LOG.md`, `HARDWARE-REQUESTS.md`, `PROGRESS.md` and `plan/10-workplan.md`, not memory. Module completion does not close scripted S4, arrangements, DPCM or the whole audio milestone.
