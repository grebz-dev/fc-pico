//==================================================
//
//		FC PICOプログラム更新方法
//
//==================================================

①FC PICOのシェルをあけて基板を取り出す


②基板上のマイコン ラズベリーパイ PICO2をBOOTモードで起動する

	マイコンボード上にある BOOTボタンを押しながらUSB Type-Cケーブルを
	パソコンに接続する。（RESETボタンが付いているマイコンボードの場合は
	USBケーブルをパソコンと接続後にBOOTボタンを押しながらRESETでもOK）
	
	BOOTモードで起動するとパソコン上にドライブが追加されます。

③プログラムを書き込む
	書き込みたいプログラムの下記バッチファイルを実行する

	sample_game\upload.bat
	
	tuto1_hw\upload.bat


④「③」でプログラム転送終了後、ファミコンに基板を差しこんで電源ON

	うまく起動しない場合はファミコンのリセットボタンを押す、電源を入れなおす
	基板を差し込み直すなどを試してみて下さい。
